Fitur unggulan

Semua yang dibutuhkan untuk mengelola file Telegram sebagai drive.

01

Folder berbasis channel

Buat channel privat sebagai folder agar koleksi file tetap rapi dan mudah ditemukan.

02

Drag & drop upload

Seret file ke dashboard, pantau antrean transfer, dan lanjutkan pekerjaan tanpa proses rumit.

03

Streaming media

Putar video dan audio langsung dari drive tanpa menunggu unduhan penuh selesai.

04

Pratinjau dokumen

Buka PDF dengan viewer bawaan dan nikmati thumbnail untuk gambar serta file media.

05

Tautan berbagi aman

Bagikan file dengan opsi kata sandi, masa berlaku, serta kontrol pencabutan akses.

06

Proxy & optimasi jaringan

Dukungan SOCKS5, MTProto, throttling, dan penyesuaian chunk untuk koneksi yang menantang.

Cara kerja

Dari kredensial API ke drive siap pakai dalam tiga langkah.

  1. Siapkan Telegram APIBuat aplikasi di my.telegram.org untuk mendapatkan API ID dan API Hash.
  2. Login di aplikasiMasukkan kredensial, verifikasi akun, lalu Telegram Drive mengindeks ruang penyimpanan Anda.
  3. Kelola fileUpload, preview, stream, susun folder, dan buat tautan berbagi dari satu dashboard.

Instalasi

Jalankan dari source.

Proyek asli membutuhkan Node.js 18+, Rust stable, build tools Tauri sesuai OS, dan kredensial Telegram API.

git clone https://github.com/caamer20/Telegram-Drive.git cd Telegram-Drive/app npm install npm run tauri dev

FAQ

Pertanyaan singkat.

Apakah data saya dikirim ke server pihak ketiga?

Tidak. Aplikasi dirancang local-first; kredensial dan data tetap berada di perangkat Anda dan layanan Telegram.

Apakah ini aplikasi resmi Telegram?

Bukan. Telegram Drive adalah proyek open-source independen dan tidak berafiliasi dengan Telegram FZ-LLC.

Platform apa saja yang didukung?

Desktop Windows, macOS, Linux, serta build Android beta yang dapat di-sideload dari rilis proyek.
